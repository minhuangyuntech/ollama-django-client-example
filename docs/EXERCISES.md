# 修改練習

先依自己的作業系統說明啟動網站，完成模型選單與中文問答，再保留一份修改前的 Git 狀態。

1. **設計用途與介面。** 修改網站名稱、問題提示及回答區，讓網站服務自己的研究或學習主題。檔案為 `chat/templates/chat/index.html` 與 `chat/static/chat/style.css`；保留模型選單、CSRF 與文字 escape。
2. **閱讀並調整驗證。** 追蹤 `AskForm → cleaned_data → ask`。測試空白問題、長度超限與不存在的模型值；確認被拒絕的表單不會送出問答請求。長度驗證由 `chat/forms.py` 設定。
3. **觀察模型與量測。** 固定同一模型及問題，依服務容量分批呼叫三次。比較載入時間、API 呼叫時間及生成速度，保留首次／後續狀態與錯誤紀錄，說明每個值的測量範圍。
4. **擴充問答情境。** 在後端加入固定用途的 system message，或設計問題分類欄位；每次變更仍需保留模型選項、輸入驗證與金鑰處理。確認 HTTP 請求的 messages 與自己的設定一致。

熟悉後可再設計多輪對話、session 或逐字串流。歷史長度增加 context 資源；前端仍只呼叫自己的 Django，API_KEY 留在後端。

提交自己修改的 Python、HTML、CSS、requirements 與操作證據。排除 `.venv`、暫存、資料庫、實際金鑰及私人設定；截圖不顯示金鑰。程式測試與真正 API 問答的結果分別紀錄。
